Static electricity and current electricity both involve electric charge, but they behave differently.

The clean distinction is:

- **Static electricity** starts with charge imbalance. That imbalance creates an electric field. It may release in a brief discharge.
- **Current electricity** needs a source that maintains a voltage difference through a closed path and a load. That produces sustained current and continuous energy transfer.

## The intuition

Static electricity is like charge piling up in one place.

Current electricity is like charge flowing through a working loop.

A balloon sticking to hair, a tiny shock from a doorknob, and lightning are static-electricity examples. A lamp, phone charger, motor, or computer uses current electricity because the flow is sustained through a circuit.

The connected lab makes the contrast visible. Build up separated charge, release a brief spark, then compare that with charge markers moving continuously through a closed loop.

## Static electricity

Static electricity begins when charge is unevenly distributed.

That charge imbalance creates an electric field. If the imbalance becomes strong enough, charges can move suddenly across a gap or through a path. That sudden movement is a discharge.

Lightning is a large static discharge, but the important point is not the direction. Lightning can be cloud-to-ground, ground-to-cloud, or cloud-to-cloud.

The important point is simpler:

```text
charge imbalance -> electric field -> possible brief discharge
```

During discharge, charges move and reduce the imbalance. The event is usually brief because the built-up difference is being corrected rather than continuously maintained.

## Current electricity

Current electricity is different because a source keeps the electrical difference going.

A battery, power supply, or generator acts like the pump in the water-flow analogy. More precisely, the source maintains the voltage difference. It does not just create it once.

For useful current electricity, the basic structure is:

```text
source -> voltage difference -> closed path -> load -> useful work
```

The load is the part that uses the transferred energy. It may produce light, heat, motion, sound, computation, or a signal.

If the path opens, the sustained current stops. If there is no load, there is no useful work. If there is no source maintaining the voltage difference, the flow cannot continue in a controlled way.

## Clean contrast

| Kind | Core structure | What happens |
| --- | --- | --- |
| Static electricity | Charge imbalance creates an electric field | The imbalance may discharge briefly |
| Current electricity | A source maintains voltage difference through a closed path and load | Current is sustained and energy transfers continuously |

## Final model

Static electricity:

```text
charge imbalance creates an electric field,
then may discharge briefly.
```

Current electricity:

```text
a source maintains voltage difference
through a closed path and load,
producing sustained current
and continuous energy transfer.
```

This lesson is a model for understanding behavior, not a guide for working on electrical systems. Real electrical systems can be dangerous and should be handled with proper training, tools, and safety rules.
