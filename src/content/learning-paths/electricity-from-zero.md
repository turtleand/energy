Electricity becomes learnable when it is a ladder, not a pile of formulas.

This path starts with intuition. First you learn what a source does, why a closed loop matters, how charge can flow, and where useful work happens. Then formulas become names for relationships you can already see.

## Who this path is for

Use this path if you want a calm first route into electricity.

It is for beginners who want to understand circuits, power, batteries, homes, grids, and generation without jumping straight into algebra or unsafe hardware work.

## The core model

Start with four anchors:

1. **Push**: a source maintains an electrical difference.
2. **Flow**: charge can move when there is a complete path.
3. **Work**: the load converts electrical energy into light, heat, motion, computation, or signal.
4. **Loop**: sustained current needs a closed route back to the source.

A simplified first model is:

```text
source creates push
closed loop allows flow
load turns energy into useful work
resistance shapes the flow
```

This is a learning model. It is not the whole physics story, but it gives the rest of the path a stable floor.

## Learning rhythm

A good electricity lesson should answer five questions:

1. What physical situation are we looking at?
2. What changes when the circuit opens or closes?
3. Where does energy enter the system?
4. Where does useful work happen?
5. What simplified model helps without pretending to be complete?

That rhythm keeps the learner grounded. It also makes later equations feel like compression, not intimidation.

## Safety boundary

This path teaches educational models. It is not a guide for real electrical work.

Mains electricity, panels, outlets, high-current batteries, generators, and grid equipment can injure or kill people. Real work requires proper training, tools, ratings, codes, and safety procedures.

Use these lessons to understand the map. Do not treat the map as permission to work on dangerous systems.
