Electricity becomes learnable when it is a ladder, not a pile of formulas.

This path starts with intuition. You first learn what a source does, why a closed loop matters, how charge moves, and where useful work happens. Formulas arrive only after the relationships are visible.

## Start with four anchors

1. **Push**: a source maintains an electrical difference.
2. **Flow**: charge moves when there is a complete path.
3. **Work**: a load converts electrical energy into light, heat, motion, computation, or signal.
4. **Loop**: sustained current needs a closed route through the circuit.

```text
source creates push
closed loop allows flow
load turns energy into useful work
resistance shapes the flow
```

This is a learning model, not the whole physics story. It gives the rest of the path a stable floor.

## Follow the ladder

### 1. Build circuit intuition

Begin with energy transfer, static charge, and the structure of a simple closed circuit. Learn to see the source, path, load, switch, and return path before solving equations.

### 2. Make the relationships measurable

Add Ohm's Law, direct and alternating current, device ratings, power, energy, and electric-bill intuition. Treat each formula as a compact description of a relationship you can already explain.

### 3. See how electricity is produced, stored, and controlled

Study conductors, insulation, grounding, fault protection, generators, transformers, and batteries. Keep the distinction clear between an educational model and safe real-world practice.

### 4. Move from devices to infrastructure

Trace electricity through household protection, neighborhood distribution, grid balancing, frequency control, and generation portfolios. The same ideas of power, energy, limits, feedback, and protection reappear at larger scales.

## Use a simple learning rhythm

For each lesson:

1. Predict what should happen.
2. Read the plain-language model.
3. Use the embedded simulation to change one thing.
4. Explain the result without copying the page.
5. Continue only when the relationship makes sense.

The goal is not to memorize every term. It is to build a connected model that can support deeper engineering later.

## Safety boundary

This path teaches educational models. It is not a guide for electrical work.

Mains electricity, panels, outlets, high-current batteries, generators, and grid equipment can injure or kill people. Real work requires appropriate training, tools, ratings, codes, and safety procedures.

Use these lessons to understand the map. Do not treat the map as permission to work on dangerous systems.
